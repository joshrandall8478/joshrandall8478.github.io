These are my dotfiles for any KDE Plasma Linux setup. Outside of KDE Plasma, they can be used on any UNIX like environment, such as macOS or other Linux environments to modify the terminal, `kitty`, and more. I created this repository to save my configs for easy global use, and quickly onboard any new KDE Plasma Linux environment to my settings and configurations using a program called [chezmoi](https://chezmoi.io).

I did make a video on this, which you can view here:

For those who don't know: Dotfiles are configuration files that are usually hidden (within `.config` or `.local`) on a linux system, and can be loaded to any user to apply those configurations.

While this project is public and can be used by anyone, this repository is not designed with other users in mind. If I wish to make drastic changes to my config, I will not be thinking of other users while doing so.

I also have other dotfile repositories that use `chezmoi` for onboarding:
